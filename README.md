# TIDE AI Club

TIDE is a student club where people learn AI by building real things together.

This is the club's website: <https://tide-o5t.pages.dev>

The main idea is simple: learning goes faster when you have people to build with. The site brings the club together in one place, so students can:

- find upcoming events and workshops
- ask questions and share work in the community forum
- start a project or join someone else's team
